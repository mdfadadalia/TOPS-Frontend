# Product CRUD React Template

Professional Bootstrap 5 React product CRUD template using static data.

## Product fields

- name: String
- price: Number
- category: String
- quantity: Number
- createdAt: Date
- updatedAt: Date

## Features

- Product listing
- Add product
- Edit product
- Delete product
- Delete confirmation
- Search
- Category filter
- Reset filters
- Product statistics
- Responsive Bootstrap 5 UI
- Bootstrap Icons
- React state-based CRUD
- No jQuery

## Run

```bash
npm install
npm run dev
```

Then open the Vite development URL.
