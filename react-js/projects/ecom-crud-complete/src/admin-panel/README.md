# Commerce Console — Static React Admin UI

This version is **UI/design only**. All API calls, authentication, GraphQL/REST fetching,
backend mutations, and server data dependencies have been removed.

## Run

```bash
npm install
npm run dev
```

## Routes

- `/login`
- `/`
- `/profile`
- `/categories`
- `/categories/new`
- `/categories/:id/edit`
- `/products`
- `/products/new`
- `/products/:id/edit`
- `/orders`
- `/orders/:id`
- `/payments`
- `/users`
- `/users/:id`

All pages use static sample data. Forms and navigation are only for demonstrating the UI.
